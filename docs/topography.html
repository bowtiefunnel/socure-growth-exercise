TargetCo Growth Exercise / Pipeline Topography

30 mock leads → suppress → enrich → score → route → enable. A deterministic pipeline with exactly two gated language leaves — the LLM appears only where language is the deliverable or the world is genuinely ambiguous; code decides everything a metric tracks.

Enrich — cascade

Score

4-dimension rubric, 0–100: hot ≥ 75 · warm 50–74 · cold < 50. Vertical matches domain evidence first — an LLM label never overrides a domain keyword.

04

Control plane

Orchestration
Trigger.dev TypeScript tasks · cloud-deployed · npm run pipeline needs zero keys
Per-stage retries, structured logs, shareable run link — "it runs" is a live artifact and pipeline-health instrumentation comes free.
LLM
Claude Haiku exactly 3 touchpoints: enrichment residue · battle cards · brief narration
Cards and narration are language deliverables; everything a metric tracks stays in cheaper, testable code.
Observability
Langfuse prompt · tokens · cost · latency per call
Groundedness eval per battle card; LLM spend is a dashboard number, not a surprise.
Delivery
Slack production rail via Trigger.dev — not in the demo run
P1 hot-lead alert + battle card to the routed rep; run summary + threshold alerts to ops; Part 2 reuses the rail for CSM expansion alerts. Reps live in Slack — the routed lead lands where the SLA clock starts.
Decision logic
config/ icp-rubric.json · routing-rules.json · enrichment.json
Changing the ICP or territories is a config edit, never a code edit; the rubric carries its evidence citations inline.
Outputs
Four artifacts routed_leads.csv/.json · battle_cards/*.md · decision_brief.md + brief.json
CSV for the brief's deliverable, JSON for machines, cards for reps, brief for the operator.
05

Data model

Lead (source fields never mutated) → enrichment{source, confidence} → score{total, breakdown, tier} → routing{rep, priority, owner_status}

One Lead accretes; leads group into an Account by registrable domain. The same account shape serves both bowtie sides — Part 2 re-points enrich→score→route at the expansion book.
