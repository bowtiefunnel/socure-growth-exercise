Only inbound door: the Webhook Relay Slack never talks to Trigger.dev directly. Signature verification, the <3s ack, and retry dedupe (idempotencyKey = event_id) all live in the Worker.
Only cross-run state: Supabase Accounts written by the batch pipeline, read by the Slack path; cards persisted as ledger rows because Trigger.dev cloud task filesystems are ephemeral.
Langfuse is observe-only Traces and groundedness scores flow in; nothing reads back at runtime — an outage there cannot block card delivery.
